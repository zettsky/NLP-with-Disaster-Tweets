        How it works

        1. Upload a Kaggle-style CSV (id, keyword, location, text[, target]) or a TXT file with one tweet per line.
        2. Tokenise each tweet. Each word has a weight: positive pushes toward “disaster”, negative toward “not”.
        3. Score = bias + Σ weights → sigmoid → probability p.
        4. Sort into three pages by p. Underlined words pushed toward disaster; struck words pushed away.
